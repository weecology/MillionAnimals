# Kaggle competitions (catalog)

Curated competition bundles that can be wired into local AnimalBoxes workflows via `data_prep/sources_kaggle/`. Access requires a Kaggle account and API credentials; files are not mirrored in this repository.

## NOAA Right Whale Recognition

- **Slug / competition id:** `noaa-right-whale-recognition`
- **Overview:** https://www.kaggle.com/competitions/noaa-right-whale-recognition/overview
- **Task:** Individual identification of North Atlantic right whales from aerial imagery (historical 2015 competition layout: `train.csv` + `imgs/`).
- **Formatter:** `data_prep/sources_kaggle/noaa_right_whale_recognition/format_for_animalboxes.py`
- **HPC notes:** `data_prep/sources_kaggle/noaa_right_whale_recognition/README.md`
