# Kaggle-derived sources

Scripts here turn **competition downloads you obtain with the Kaggle API** into the shared MillionAnimals annotation shape (`geometry`, `image_path`, `label`, `source`) for `data_prep/package_datasets.py --bootstrap-annotations`.

| Competition | Folder |
|-------------|--------|
| [NOAA Right Whale Recognition](https://www.kaggle.com/competitions/noaa-right-whale-recognition/overview) | `noaa_right_whale_recognition/` |

Do not commit competition archives or extracted images.
